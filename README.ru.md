## 🚀 Избранные проекты

### 01 / DentLux

**Управление стоматологической клиникой · Fullstack-приложение**

Проект охватывает сценарии пациента, врача и администратора. В репозитории представлены управление записями на приём, модели платежей и возвратов, медицинские записи и конфигурация развёртывания.

| Направление | Что посмотреть |
| :--- | :--- |
| Продукт | Отдельные интерфейсы пациента, врача и администратора |
| Frontend | React, TypeScript, Vite, Tailwind CSS |
| Backend | Node.js, Express, PostgreSQL, Prisma |
| Развёртывание | Docker Compose; конфигурация Terraform и Ansible |
| Бизнес-анализ | Участники процесса, жизненный цикл записи, бизнес-правила и примеры критериев приёмки |

[Посмотреть код ↗](https://github.com/AdilMoon/DentLux) · [Прочитать бизнес-кейс ↗](docs/dentlux-case-study.md#русский) · [Посмотреть модель данных ↗](https://github.com/AdilMoon/DentLux/blob/main/backend/prisma/schema.prisma)

### 02 / HopeStep

**Изучение языков · Android-приложение**

Проект приложения для изучения языков на Kotlin с Jetpack Compose и Room. Дополняет веб-портфолио опытом мобильной разработки.

[Посмотреть код ↗](https://github.com/AdilMoon/HopeStep) · [Конфигурация Android ↗](https://github.com/AdilMoon/HopeStep/blob/main/app/build.gradle.kts)
